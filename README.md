# Car Sale API

Simple ASP.NET Core Web API for learning REST API, SQL Server and Dapper.

## Database

Execute:

```sql
Database/CarSaleDb.sql
```

## Configuration

Update connection string in:

```text
appsettings.json
```

## Run

Run the application and open Scalar.
